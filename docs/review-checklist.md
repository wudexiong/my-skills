# 收录标准（review-checklist）

候选技能进 `skills/` 前，逐项核对：

## 必过项
- [ ] `SKILL.md` 存在，frontmatter 有 `name`（kebab-case、与目录同名）+ `description`（一句话、准确）
- [ ] 自包含：不依赖技能目录外的路径（scripts/ 自带）
- [ ] 有"环境自举"章节：首次调用自动检查环境、装依赖
- [ ] 无敏感信息（token、cookie、密码不入库）
- [ ] 许可证允许使用/分发（README/目录内注明来源）

## 加分项
- [ ] `whenToUse` 写清楚适用/不适用场景
- [ ] 有 tests 或可验证的输出
- [ ] 与已有技能不重复（查 index.json）
- [ ] 有真实使用记录（我用过 / 别人验证过）

## 否决项
- 与已有技能功能重复且无增量价值
- 依赖外部私有服务/账号且无法自举
- 来源不明、许可证不允许
