# inbox — 原始经验暂存区（未门控）

项目收尾时，`feed.mjs` 把经验写到这里（原始，不加工）。

## 经验门控三标准（达标才进 digest/wiki）

一条经验必须**同时满足**才值得回流：

| 标准 | 判定 | 例子 |
|---|---|---|
| ✅ 跨任务可复用 | 换项目/任务还用得上 | "Next.js 16 app router 改版坑" ✅ |
| ✅ 重复出现 ≥2 次 | 踩过一次是事故，两次是规律 | "两个项目栽在 supabase RLS" ✅ |
| ✅ 稳定不过时 | LLM 训练数据里没有，需真实环境验证 | "frp 国内必须走镜像源" ✅ |

**不达标就丢弃**：LLM 本来就知道的、项目特有一次性、纯主观偏好。

## 流程

`feed.mjs` 写入 → 定期跑 `digest.mjs` 编译（按三标准判定）→ 达标的进 `../wiki/` → 原始文件归档/删除
